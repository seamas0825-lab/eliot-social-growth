# Run Modes

Choose the least expensive mode that can safely change the decision. The evidence counts below are planning guardrails, not statistical sufficiency claims.

## Light

Use for a reversible decision with one dominant uncertainty.

- Typical effort: 15–30 minutes.
- Inspect 3–5 directly accessible sources representing at least two source roles when available.
- Do not open authenticated web-AI branches by default.
- Record the decision, strongest contrary evidence, confidence, and one cheap experiment.
- Stop when one safe test is clearly more informative than additional desk research.

Escalate to Standard when sources materially conflict, the user asks for a multi-platform plan, or execution commits meaningful budget or reputation.

## Standard

Use by default for a costly but reversible positioning, launch, channel, or content-system decision.

- Typical effort: 1–3 hours, adjusted for browser and market access.
- Cover 2–4 source-role branches and roughly 8–15 material cases when available.
- Use at most the smallest distinct set of web-AI services that fills genuine evidence gaps.
- Maintain run state, a compact belief audit, source ledger, hard choice, and falsifiable experiment.
- Stop when remaining uncertainty no longer changes the first experiment.

Escalate to Deep for high-stakes claims, multi-market or multilingual comparisons, sensitive audiences, regulation, or an evidence conflict that reverses the planned decision.

## Deep

Use for hard-to-reverse, reputation-sensitive, regulated, multi-market, or multilingual decisions.

- Typical effort: several hours to multiple working sessions.
- Use independent source roles, explicit contradiction search, language or cultural validation, and primary-source verification.
- Use human decision, taste, contradiction, and reality checkpoints where material.
- Save browser/AI branch metadata and run the evaluation harness for the final response or artifact.
- Stage execution so the earliest reversible test occurs before a full rollout.
- Stop only when remaining gaps are explicitly bounded and owners or experiments exist for them.

## Changing modes

Record any mode change in run state with the trigger. Do not silently expand Light into a large research program. Do not keep Deep mode alive merely to collect more links after the decision and first experiment have stabilized.
